# 右侧栏「选字幕 → 再记录」交互设计

> 2026-11-01

## 问题

用户点击「＋ 记录此刻想法」后直接弹出输入框，但想法缺乏上下文——不知道是针对哪段内容产生的。需要让用户先选定相关的原文字幕，再记录想法，建立笔记与内容的关联。

## 方案

### 交互流程

**Step 1：点击「＋ 记录此刻想法」**
- 不直接弹 modal
- 右侧栏进入**「选择模式」**：
  - 原文字幕区域顶部出现提示条：`🎯 点击选择相关原文（可多选）`
  - 每行字幕变为可点击（hover 有高亮反馈）
  - 点击某行 → 该行被选中（蓝色背景标记），再点取消
  - 底部出现浮动操作条：`已选择 3 段 ── [取消] [确认并记录想法 →]`

**Step 2：确认选择后**
- 弹出 note modal（和现在一样）
- modal 顶部显示选中的字幕摘要：`针对：00:15 ~ 01:10 的 3 段原文`
- 用户输入想法 → 保存

### 关键细节

- 选择模式下，字幕区仍然可以滚动浏览，不影响正常阅读
- 如果不选任何字幕，直接点 modal 的关闭/取消 → 退出选择模式，回到正常状态
- 选择模式有「取消」按钮可退出
- 已选字幕的时间范围会自动传入 modal（替代现在的「当前播放时间」）

### 改动范围

- `build_prototype_v3.py`：
  - 新增选择模式的 CSS（字幕选中样式、提示条、底部操作条）
  - 新增 JS 逻辑（选择模式开关、字幕点击选中/取消、计数、确认回调）
  - notequick 按钮的 onclick 改为进入选择模式（而非直接 openNoteModal）
  - modal 顶部增加选中摘要
